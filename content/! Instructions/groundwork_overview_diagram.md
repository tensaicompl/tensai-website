# Diagram Brief — Pillar I: The Groundwork Overview

## Title
The Six Decisions — and the Chain Between Them

## Single idea the diagram conveys
The Groundwork is a dependency chain of six structural decisions, each building on the one before it, with the operating model as the foundation and FinOps as the closing loop that makes the whole structure economically sustainable.

## Layout description
A vertical composition — six nodes arranged in a single descending column, connected by directional arrows, with a return arrow from the bottom node back to the top to close the loop. The column reads top to bottom as a chain of dependencies.

### The six nodes

Six rectangular blocks, equal width, stacked vertically with equal spacing. Each block contains a two-digit number (left-aligned, italic, display weight) and a title (right of the number, semibold). A single-line subtitle sits beneath the title in lighter weight.

1. **01 — Operating Model & Maturity**
   Subtitle: "Structure the organisation"

2. **02 — Build · Buy · Boost**
   Subtitle: "Decide where to invest"

3. **03 — Token Sourcing**
   Subtitle: "Source the commodity"

4. **04 — Security Architecture**
   Subtitle: "Defend the surface"

5. **05 — Governance & Risk**
   Subtitle: "Govern the system"

6. **06 — FinOps for AI**
   Subtitle: "Prove the economics"

### The connections

- A thin vertical arrow connects each node to the one below it — five arrows total, flowing downward. These represent the dependency chain: each decision assumes the one above it.
- A single return arrow curves from the bottom of node 06 (FinOps) back up to the top of node 01 (Operating Model). This arrow arcs to the right of the column, forming a visible loop. It is drawn in a lighter stroke weight than the downward arrows — it is the feedback path, not the primary flow. A small label sits beside the return arrow, reading: "Economics validate structure".

### The throughline

A vertical line runs along the left edge of the column, spanning from the top of node 01 to the bottom of node 06. This line is the throughline — a visual anchor. At the top of this line, a small label reads: "AI is an operating decision before it is a technology one." The label is set in italic, aligned flush left with the line, positioned above node 01.

### Altitude marker (optional, right side)

A subtle bracket or vertical label on the right side of the column, spanning all six nodes, reading: "CTO / CIO altitude". This anchors the pillar at its intended audience level and distinguishes it from the other two pillars if the diagram is ever shown in a cross-pillar context.

## Style notes
- **Background:** off-white (`#FAFAFA`)
- **Node blocks:** midnight (`#0F172A`) — 1px stroke, no fill, rounded corners (4px radius). Interior padding comfortable enough for the number, title, and subtitle to breathe.
- **Node numbers (01–06):** midnight, display font, italic, 20px — left-aligned within each block
- **Node titles:** midnight, display font, semibold, 15px — right of the number
- **Node subtitles:** midnight at 50% opacity, body font, regular, 12px — beneath the title
- **Downward arrows:** midnight at 70% opacity, 1.5px stroke, simple arrowhead
- **Return arrow (FinOps → Operating Model):** violet (`#6D28D9`), 1.5px stroke, dashed — the only colour in the diagram, drawing the eye to the feedback loop that closes the chain
- **"Economics validate structure" label:** violet, 11px, regular weight — positioned beside the return arrow's midpoint
- **Throughline line (left edge):** midnight at 25% opacity, 1px stroke, vertical
- **Throughline label:** midnight at 50% opacity, 12px, italic
- **Altitude marker (right side):** midnight at 30% opacity, 11px, uppercase, letter-spaced — subtle, not competing with the primary content
- **No gradients, no shadows, no fills, no decoration.** Line art only.
- **Vertical spacing:** equal gaps between all six nodes. The diagram should be taller than it is wide — portrait orientation, emphasising the downward chain.
